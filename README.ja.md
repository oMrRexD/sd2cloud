**PS2 のメモリーカードを本体で管理・バックアップ。**

[![Downloads](https://img.shields.io/github/downloads/oMrRexD/sd2cloud/total?style=for-the-badge&logo=github)](https://github.com/oMrRexD/sd2cloud/releases/latest)
> [!WARNING]
> SD2Cloud は、セーブデータのコピー、移動、削除、インポート、復元や、カードの作成、容量の変更、削除のときに
> メモリーカードを書き換えます。その前にバックアップを取ってください（カードを Google ドライブと同期するか、
> microSD の `MemoryCards` フォルダーを PC にコピー）。

SD2Cloud は PS2 本体で動作します。[sd2psXtd](https://github.com/sd2psXtd/firmware) ファームウェアを搭載した sd2psx 系
デバイス（sd2psx、PSXMemCard、PSXMemCard Gen2、PicoMemcard+/Zero。PS2 からは MMCE と呼ばれます）と MemCard PRO2 の
microSD にあるメモリーカード、通常のメモリーカード、OPL の仮想メモリーカード（VMC）、USB ドライブ、MX4SIO、内蔵 HDD
にあるメモリーカードのファイルを扱います。PC は必要ありません。

## 機能

**クラウド同期**
- メモリーカードを Google ドライブと同期します。手動でも、IGR でゲームを終了するたびに自動でも同期できます。
  変更されたカードだけがアップロードされます。
- カードごとにバックアップの履歴を残し（既定では 10 個）、どれでも復元できます。書き込みの前後に検証します。
  変更されたカードは復元の前に同期されるので、何も失われません。
- 各カードは sd2psx 自身の `.mcd` 形式で送られます。設定で選べば、PCSX2 が使う `.ps2` 形式でも送れます。バックアップの
  zip から取り出せば、そのままエミュレーターで使えます。どちらの形式も復元できます。
- **セーブデータごとのバックアップ**: 必要なら、変更された各セーブデータもバージョン付きで個別に送ります。
  セーブデータのページの **ドライブのバージョン** から、どのバージョンにも戻せます。
- バックアップを機器・ゲーム・カードごとのフォルダーに整理し（カードごとにセーブデータのフォルダー付き）、
  **ファイル** タブから閲覧できます。セーブデータのページ、カードとして開いたりインストールしたりできるカードの
  バックアップ、任意のファイルのダウンロードや削除ができます。
- サインインはコードまたは QR コードで一度だけ。SD2Cloud がアクセスできるのは、ドライブ上で自分が作成したファイルだけです。

**メモリーカードマネージャー**
- 各カードのセーブデータを、PS2 ブラウザーと同じように動く 3D アイコン付きで表示します。
- カード間でセーブデータをコピー、移動、削除し（1 枚または複数のカードで選んだものをまとめて）、1 つのセーブデータを
  `.psu` ファイルとして Google ドライブにアップロードします。
- **ライブラリ**: セーブデータをカードの外に保管します（いっぱいになったメモリーカードや、削除せずにカードから
  出したいセーブデータ）。ゲームごとに 1 つずつファイルにして、容量の制限はありません。必要ならドライブにも送ります。
- **カードのツール**: カードを作成し（番号付き、自分のフォルダー、または任意のデバイス上のカードのファイル。
  sd2psx では 1〜64 MB、MemCard PRO2 では 8〜128 MB、推奨容量付き）、容量の変更、名前の変更、チェック、削除ができます。
  **カードを Game ID 形式に変換** して、各ゲームのセーブデータをそのゲームのカードにコピーすることもできます
  （1 つの画面で、残り時間付き）。データを失うおそれのある変更の前には、カードの **安全コピー** を残し、ツールから
  元に戻せます。
- カードをタブに分けて整理します。番号付きのカードと自分のフォルダー、ゲーム名のフォルダーに入ったゲーム
  （Game ID）のカード、ブートカード、**OPL の VMC**（各 VMC を使うゲーム付き。HDD、MX4SIO、USB ドライブの VMC
  フォルダーも）、ライブラリです。
- すべてのゲームカードのセーブデータを、1 枚のカードのように 1 つの画面に表示します（「ゲーム」タブの
  **すべてのセーブデータ**）。
- sd2psx が使用中のカードを示し、別のカードに切り替えられます。使用中のカードを変更するときは、確認してから
  sd2psx を別のカードに切り替え、元に戻します。
- **ファイル** タブで MMCE、USB ドライブ、内蔵 HDD（exFAT、FAT32、APA。PSBBN のインストーラーで両方を持つディスクも）、
  MX4SIO を開けます。`.psu` ファイルやフォルダー形式のセーブデータのインポートとエクスポート、メモリーカードの
  ファイル（`.mcd`、`.mc2`、`.ps2`、OPL の `.bin`、`.zip`）を開いて、カードとして、または選んだ形式のカードの
  ファイルとして任意のデバイスにインストールし、カード全体を `.zip` としてフォルダーにコピーできます。
- 本体のスロットにある通常の **メモリーカード** を管理します。セーブデータの操作、カード全体のドライブへの
  アップロードと、そこからの復元ができます。
- sd2psx と MemCard PRO2 の両方のカードがある microSD では、**L2 と R2** で 2 つのデバイスのカードを切り替え、
  セーブデータを互いにコピーできます。
- **テンプレート** を保存します。カードで選んだセーブデータのセットで、一度に任意のカードへ書き込めます。1 つを
  すべてのゲームカードに入れるべき **デフォルト** にでき、すべてのカードに一度に書き込まれ、新しいゲームのカードには
  SD2Cloud を開いたときに提案されます。自動同期では、ゲームが使ったカードがゲームを終了するときに自動でテンプレートを
  受け取ります。**ツール**（SELECT）にあります。

**その他**
- **sd2psx なしでも動作**: USB ドライブ、MX4SIO、内蔵 HDD から起動すると、そこにデータを保存し、両方のスロットの
  メモリーカード（セーブデータごとにバックアップ）、OPL の VMC、カードのファイルを管理します。
- SD2Cloud を開いたまま sd2psx を抜き差しできます。画面がそれに合わせて更新されます。
- データをアップロード、書き込み、削除する操作の前には、必ず確認します。
- 本体上の設定（START）はページに分かれ、`sd2cloud.ini` に保存され、PC でも編集できます。
- MMCE、メモリーカード、USB、MX4SIO、内蔵 HDD（exFAT または APA）上の OPL に戻ります。そのデバイスの
  ドライバーだけを読み込みます。
- 他のプログラムを起動します。デバイスのフォルダーで選んだ ELF（**ファイル** で選んで ○、または終了時の
  「ELF を実行...」）や、Save Application System の方式でメモリーカードに保存されたアプリケーション
  （そのページの「アプリケーションを起動」）。
- このリポジトリのリリースから自動で更新し、GitHub の SHA-256 で検証します。チャンネルは設定で選べます。
  リリースされたバージョンの **安定版** と、変更のたびに自動で作られ、リリース前のテストを経ていない **ベータ**
  （[ベータのプレリリース](../../releases/tag/beta)）です。
- PlayStation BB Navigator にインスパイアされたインターフェース。
- 英語、ポルトガル語、スペイン語、ロシア語、ウクライナ語、日本語に対応。翻訳を歓迎します。
  [Translating](CONTRIBUTING.md#translating) をご覧ください。日本のゲームのセーブデータは日本語のタイトルで表示されます。

## 必要なもの

- 次のいずれか:
  - sd2psXtd ファームウェア（MMCE 対応）を搭載した sd2psx 系デバイス。
  - MemCard PRO2。`/PS2` にある `.mc2` カードを読み書きします。アプリからのカード切り替え（「このカードを挿入」）は
    そこでは試験的な機能で、SD2Cloud が自分でカードを切り替えることはありません。使用中のカードを変更するには、
    先に別のカードに切り替えてください。
  - どちらもない場合: USB ドライブ、MX4SIO、内蔵 HDD に置いた SD2Cloud と、スロットの通常のメモリーカード。
- SD2Cloud を起動する手段: OPL の Apps タブ、wLaunchELF、または ELF を実行できるその他のランチャー。
  [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader) のような MMCE 対応の OPL をおすすめします。対応していない
  OPL では、MMCE にあるアプリが表示されず、**IGR Bootcard Slot(s)** オプションもありません。その場合、Game ID の
  カードでは IGR で終了しても sd2psx がゲームのカードのままになり、PS2 は SD2Cloud を開かずにブラウザーに戻るため、
  自動同期は行われません。
- ゲーム後の自動同期には、IGR で SD2Cloud を起動する OPL。
- クラウド機能には、ネットワークアダプター（薄型モデルは内蔵）を備え、ケーブルでルーターに接続された PS2 と、
  Google アカウント。

## インストール

1. [最新のリリース](../../releases/latest) から `SD2Cloud-vX.Y.zip` をダウンロードします。
2. MMCE のルートに展開します。`APPS/SD2Cloud`（アプリ）と、各設定を説明した `SD2Cloud/sd2cloud.example.ini` が追加されます。
   設定ファイル（`SD2Cloud/sd2cloud.ini`）は SD2Cloud が初回起動時に作成するため、新しいバージョンを上書きで展開しても設定は保持されます。
   初回起動の前に PC で設定したい場合は、`sd2cloud.example.ini` の名前を `sd2cloud.ini` に変更して編集します。
   OPL の Apps タブで SD2Cloud に表示されるカバーとロゴは
   `ART` フォルダーに入ります。ポルトガル語の一文が入った同じアートが `Extras/ART pt-BR` にあり、この 2 つの
   ファイルに上書きコピーできます。
3. SD2Cloud を開きます。OPL の Apps タブから、または任意のランチャー（たとえば wLaunchELF）で
   `APPS/SD2Cloud/SD2CLOUD.ELF` を実行します。フォルダーは `APPS` になくてもかまいません。
4. 求められたら（またはあとで 設定 > Google ドライブ から）Google アカウントを接続します。スマートフォンやパソコンで
   google.com/device を開くか QR コードを読み取り、テレビに表示されたコードを入力します。
5. 続いて SD2Cloud が、自動同期をオンにしてすべてのカードを同期するよう提案します。

**sd2psx なしの場合** は、zip を USB ドライブ（FAT32 または exFAT）、MX4SIO、内蔵 HDD に展開し、そこから
`APPS/SD2Cloud/SD2CLOUD.ELF` を開いてください。SD2Cloud は設定とデータをそのデバイスに保存します。同期するのは
スロットのメモリーカードで、セーブデータごとに送ります（セーブデータごとのバックアップは最初からオン）。最初の同期で
それらを提案します。そのデバイスにある sd2psx のフォルダーはただのファイルです。**ファイル** タブから開いてください。

sd2psx がある場合も、SD2Cloud を USB ドライブ、MX4SIO のカード、内蔵 HDD（exFAT または APA）に置けます。
`APPS/SD2Cloud` フォルダーをそこに置き、一度そこから SD2Cloud を開いてください。SD2Cloud は自分の場所を記録し、
そのデバイスから起動するために SAS パッケージが必要とするドライバーを MMCE（`SD2Cloud/drivers`）に保存し、その場所で
更新されます。設定とデータは MMCE に残ります。

**メモリーカード上: SAS パッケージ。** 自動同期をオンにすると、SD2Cloud は使用中のメモリーカードに SAS（Save
Application System）パッケージを書き込みます。`APP_SD2CLOUD` フォルダーで、OPL が IGR で実行するものと、SD2Cloud を
どこにあっても開くショートカットが入っており、PS2 ブラウザー用の 3D アイコンも付いています（約 240 KB。sd2psx がない
場合は、SD2Cloud のあるデバイスのドライバーも入り、約 90 KB 増えます）。プログラム本体は元の場所に残ります。zip には
同じパッケージが `Extras/APP_SD2CLOUD.psu` としても入っており、手動で別のカードにインポートできます（SD2Cloud 自身の
**ファイル** タブでも可能）。SD2Cloud をその場所から一度開けば、ショートカットが見つけられるようになります。

**2.0 より前のバージョンからの場合**: ドライブ上のバックアップには、起動時に一度だけ新しい構成（機器・ゲーム・
カードごと）への整理が提案されます。ファイルは再アップロードせずに移動されます。「あとで」を選ぶと以前の構成の
ままになり、設定 > Google ドライブ からもう一度選べます。

リリースに含まれる [README.txt](package/README.txt) では、各画面を詳しく説明しています（英語）。

## ゲーム後の自動同期（IGR）

1. SD2Cloud で 設定（START）> 自動同期 を開き、**SAS パッケージ** を選びます（サインイン直後にも提案されます）。
   SD2Cloud は必要な容量（約 240 KB）を表示し、使用中のメモリーカードに `APP_SD2CLOUD` フォルダーを書き込む前に
   確認します。Autoboot を使う場合は、BootCard を使用中のときにインストールしてください。
2. OPL の設定で **IGR Path** を `mc0:/APP_SD2CLOUD/IGR.ELF` にします（sd2psx がスロット 2 にある場合は `mc1:`。
   パッケージのインストール時に SD2Cloud が使うべきパスを表示します）。バージョン 1.5 までがカードにヘルパーを
   残している場合（`mc0:/BOOT/SD2CLOUD-IGR.ELF`）、そのパスも引き続き使えます。パッケージをインストールすると、
   そのファイルも最新になります。
3. OPL で **IGR Bootcard Slot(s)**（MMCE のページ）もオンにし、sd2psx のスロットまたは BOTH を選びます。ゲームを
   終了すると、OPL はパッケージがインストールされている BootCard に戻ります。

これ以降、IGR でゲームを終了すると SD2Cloud が起動し、変更されたカードをアップロードして OPL に戻ります。同じ
項目でパッケージの再インストールやアンインストールができます。SD2Cloud は MMCE でもほかのデバイスでも、どの
フォルダーにでも置けます。開くたびにその場所を記録し（MMCE の `sd2cloud.ini` に。sd2psx がない場合はパッケージ自体に、
そのデバイスのドライバーと一緒に）、パッケージはそこから起動します（`APPS` のフォルダーの名前を変えた場合も見つけ
られます）。

すべてをインストールしたまま同期を一時停止するには、設定で **自動同期** をオフにします。IGR は SD2Cloud を起動せず、
そのあとに開くプログラムに直接進みます。Google アカウントが接続されていない間も同じです。

**何もインストールしない方法（USB ドライブ）。** OPL の IGR は USB ドライブのプログラムも起動できます。
`APPS/SD2Cloud` フォルダーが FAT32 でフォーマットされた USB ドライブにある場合は、手順 1 を省いて **IGR Path** を
`mass:/APPS/SD2Cloud/SD2CLOUD-IGR.ELF` にします。メモリーカードには何も書き込まれません。このとき OPL は、FMCB が
インストールする `mc?:/SYS-CONF` の USB ドライバー `USBD.IRX` と `USBHDFSD.IRX` を読み込みます。メモリーカードに
SAS パッケージがあれば、SD2Cloud がどこにあってもこれらは不要です。パッケージは MMCE、USB ドライブ、MX4SIO、HDD の
どこからでも SD2Cloud を起動します。OPL が MMCE にない場合は、`sd2cloud.ini` の `[igr]` セクションにそのパスを
デバイスから書きます: `mc?:/`（メモリーカード）、`mass:/`（USB）、`mx4sio:/`、`ata:/`（内蔵 HDD、exFAT）、または
`hdd0:パーティション:pfs:/`（内蔵 HDD、APA）。たとえば `hdd0:__common:pfs:/APPS/OPL/OPNPS2LD.ELF` です。

## プライバシー

メモリーカードは PS2 からあなた自身の Google ドライブへ直接送られます。ほかのサーバーは関与せず、何も収集しません。
SD2Cloud は `drive.file` スコープを使うため、自分が作成したファイルしか見えません。アクセス権は
[myaccount.google.com/permissions](https://myaccount.google.com/permissions) でいつでも取り消せます。Google のほかに
SD2Cloud が接続するのは GitHub だけで、それも設定で「アップデートを確認」を選んだときだけです。

## ビルド

SD2Cloud は C で書かれており、[ps2dev](https://github.com/ps2dev) のツールチェーン（ps2sdk、ps2sdk-ports、gsKit）を使います。

1. `tools/build_ports.sh` が、4096 ビット RSA に対応した wolfSSL と curl を `ports4096/` にビルドします（Google の HTTPS
   に必要です）。
2. `tools/build_mmceman.sh` が sd2psx のドライバーである mmceman を `third_party/mmceman/` にビルドします（SDK に付属
   するものは、長い転送の途中で sd2psx を止めてしまうことがあります）。
3. Google Cloud Console で種類が「TVs and Limited Input devices」の OAuth クライアントを作成して Drive API を有効にし、
   `src/credentials.h` を生成します: `python tools/make_credentials.py client_secret.json src/credentials.h`。
4. `make` で `dist/SD2CLOUD.ELF` と、`igr/` に SAS パッケージの 2 つの小さなプログラム（IGR ヘルパーとショートカット）
   がビルドされます。`make DEBUG=1` で PCSX2 用のデバッグ版がビルドされます。
5. `python tools/make_release.py` が `package/` のテキストとともにリリースを `dist/` にパッケージします。

`make -C tests` は、PS2 のツールチェーンなしで PC 自身のコンパイラーを使って回帰テストを実行します。
[tests/README.md](tests/README.md) をご覧ください。[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) はコードの地図です。
