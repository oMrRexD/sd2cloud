**PS2 のメモリーカードを本体で管理・バックアップ。**

[![Downloads](https://img.shields.io/github/downloads/oMrRexD/sd2cloud/total?style=for-the-badge&logo=github)](https://github.com/oMrRexD/sd2cloud/releases/latest)
> [!WARNING]
> SD2Cloud は、セーブデータのコピー、移動、削除、インポート、復元のたびに、またカードの作成、容量の変更、削除の
> たびに、メモリーカードに書き込みます。先にバックアップを取ってください。カードを Google ドライブと同期するか、
> microSD の `MemoryCards` フォルダーを PC にコピーします。

SD2Cloud は PS2 本体で動くアプリです。PC は必要ありません。メモリーカードを Google ドライブにバックアップし、
セーブデータを本体の上で整理できます。

対応しているもの:
- **sd2psx 系のデバイス**（sd2psx、PSXMemCard、PSXMemCard Gen2、PicoMemcard+/Zero）で、
  [sd2psXtd](https://github.com/sd2psXtd/firmware) ファームウェアを搭載したもの。PS2 からは、これらのデバイス
  （とその microSD）は **MMCE** と呼ばれます。このページでもその名前を使います。
- **MemCard PRO2**。
- **通常のメモリーカード**: 本体のスロットに挿す実物のカード。
- **OPL の VMC**（仮想メモリーカード）と、USB ドライブ、MX4SIO、内蔵 HDD に置いたその他のメモリーカードのファイル。

## 機能

**Google ドライブへのバックアップ**
- メモリーカードを Google ドライブと同期します。好きなときに手動で、または IGR（In-Game Reset。OPL でゲームを
  終了するボタンの組み合わせ）でゲームを終了するたびに自動で同期できます。アップロードされるのは変更された
  カードだけです。
- カードごとにバックアップの履歴を残し（既定では 10 個）、どれでも復元できます。カードは書き込みの前後に検証
  されます。最後のバックアップのあとにカードが変更されていた場合、SD2Cloud はそのカードを先にバックアップして
  から別のバックアップで上書きするので、何も失われません。
- 各カードは sd2psx 自身の形式である `.mcd` ファイルとしてアップロードされます。設定で `.ps2` を選ぶこともでき
  ます。これは PCSX2 の形式なので、バックアップの zip から取り出したカードはそのままエミュレーターで使えます。
  どちらの形式も復元できます。
- **セーブデータごとのバックアップ**（任意）: 変更された各セーブデータも個別のファイルとしてアップロードし、
  以前のバージョンも残します。セーブデータのページの **ドライブのバージョン** から、どのバージョンにも戻せます。
- ドライブ上のバックアップは、機器・ゲーム・カードごとのフォルダーに整理され、カードごとに Saves フォルダーが
  あります。**ファイル** タブから閲覧でき、セーブデータのページを開く、カードのバックアップをカードとして開く、
  それをインストールする、任意のファイルをダウンロード・削除する、といった操作ができます。
- Google アカウントの接続は、コードまたは QR コードで一度だけです。SD2Cloud がドライブ上で見られるのは、自分で
  作成したファイルだけです。

**メモリーカードマネージャー**
- 各カードのセーブデータを、PS2 のブラウザーと同じように、動く 3D アイコン付きで表示します。
- カード間でセーブデータをコピー、移動、削除します。複数のセーブデータを、別々のカードからでもまとめて扱えます。
  1 つのセーブデータを `.psu` ファイル（PS2 のセーブデータ 1 つ分の一般的な形式）として Google ドライブに
  アップロードすることもできます。
- **ライブラリ** は、セーブデータをカードの外に保管します。1 つずつ別のファイルにし、ゲームごとに分け、容量の
  制限はありません。メモリーカードがいっぱいのときや、削除せずにカードから出したいセーブデータがあるときに
  便利です。ドライブにも置けます。
- **カードのツール** で、カードの作成、容量の変更、名前の変更、チェック、削除ができます。
  - 新しいカードは、番号付きのカード、好きな名前のフォルダーに入れたカード、または任意のデバイス上のカードの
    ファイルにできます。容量は sd2psx では 1〜64 MB、MemCard PRO2 では 8〜128 MB で、推奨容量に印が付きます。
  - **Game ID 形式に変換** は、1 枚のカードをゲームごとのカードに分けます。Game ID のカードとは、ゲームの起動時に
    sd2psx が自動で切り替えるカードのことです。すべて 1 つの画面で行われ、残り時間が表示されます。
  - データを失うおそれのある変更の前には、SD2Cloud がカードの **安全コピー** を残します。ツールから元に戻せます。
- カードはタブに分けて表示されます。番号付きのカードと自分のフォルダー、ゲーム名のフォルダーに入ったゲーム
  （Game ID）のカード、ブートカード、**OPL の VMC**、ライブラリです。VMC のタブには、各 VMC を使うゲームが表示
  され、HDD、MX4SIO、USB ドライブの VMC フォルダーも入ります。
- 「ゲーム」タブの **すべてのセーブデータ** は、すべてのゲームカードのセーブデータを、1 枚のカードのように 1 つの
  画面に表示します。
- sd2psx が使用中のカードを示し、別のカードに切り替えられます。使用中のカードを変更するときは、SD2Cloud が先に
  確認し、作業のあいだ sd2psx を別のカードに切り替えて、終わったら元に戻します。
- **ファイル** タブでは、MMCE、USB ドライブ、内蔵 HDD、MX4SIO を閲覧できます。HDD は exFAT、FAT32、APA に対応し、
  PSBBN のインストーラーで両方を持つようになったディスクも使えます。ここでできること:
  - `.psu` ファイルとフォルダー形式のセーブデータのインポートとエクスポート。
  - メモリーカードのファイル（`.mcd`、`.mc2`、`.ps2`、OPL の `.bin`、`.zip`）を開き、カードとして、または好きな
    形式のカードのファイルとして任意のデバイスにインストールする。
  - カード全体を `.zip` としてフォルダーにコピーする。
- 本体のスロットにある通常の **メモリーカード** を管理します。セーブデータの操作のほか、カード全体をドライブに
  アップロードし、そこから復元できます。
- microSD に sd2psx と MemCard PRO2 の両方のカードがある場合、**L2 と R2** で 2 つのデバイスのカードを切り替え、
  セーブデータを互いにコピーできます。
- **テンプレート**: カードから選んだセーブデータのセットで、どのカードにも一度に書き込めます。1 つを **デフォルト**
  のテンプレート、つまりすべてのゲームカードに入れておくべきものにできます。デフォルトはすべてのカードに一度に
  書き込めるほか、新しいゲームのカードに入っていないときは、SD2Cloud が起動時に書き込みを提案します。自動同期を
  使うと、ゲームが使ったカードは、ゲームを終了したときに自動でテンプレートを受け取ります。テンプレートは
  **ツール**（SELECT）にあります。

**その他**
- **sd2psx なしでも動作**: USB ドライブ、MX4SIO、内蔵 HDD から起動すると、データをそこに保存します。両方のスロット
  のメモリーカード（セーブデータごとにバックアップ）、OPL の VMC、カードのファイルを管理します。
- SD2Cloud を開いたまま sd2psx を抜き差しできます。画面は自動で追従します。
- データをアップロード、書き込み、削除する操作の前には、必ず確認します。
- 設定は本体の上（START）にあり、ページに分かれています。設定は `sd2cloud.ini` に保存され、PC でも編集できます。
- 終了時には、MMCE、メモリーカード、USB、MX4SIO、内蔵 HDD（exFAT または APA）の OPL に戻れます。読み込むのは
  そのデバイスのドライバーだけです。
- ほかのプログラムを起動します。デバイスのフォルダーにある ELF（**ファイル** で選んで ○、または終了時の「ELF を
  実行...」）と、Save Application System の形式でメモリーカードに保存されたアプリケーション（そのページの
  「アプリケーションを起動」）です。
- このリポジトリのリリースから自分で更新し、ダウンロードしたファイルを GitHub が公開している SHA-256 で検証します。
  チャンネルは設定で選べます。
  - **安定版**: リリースされたバージョン。
  - **ベータ**: 変更のたびに自動で作られるビルドで、リリースが受けるテストの前の段階のもの
    （[ベータのプレリリース](../../releases/tag/beta)）。
- PlayStation BB Navigator にインスパイアされたインターフェース。
- 英語、ポルトガル語、スペイン語、ロシア語、ウクライナ語、日本語に対応。翻訳を歓迎します。
  [Translating](CONTRIBUTING.md#translating) をご覧ください。日本のゲームのセーブデータは日本語のタイトルで表示されます。

## 必要なもの

- 次のいずれか:
  - sd2psXtd ファームウェア（MMCE 対応）を搭載した sd2psx 系デバイス。
  - MemCard PRO2。SD2Cloud は `/PS2` フォルダーにある `.mc2` カードを読み書きします。PRO2 では、アプリからの
    カード切り替え（「このカードを挿入」）はまだ試験的な機能で、SD2Cloud が自分でカードを切り替えることはありません。
    使用中のカードを変更するには、先に別のカードに切り替えてください。
  - どちらもない場合: USB ドライブ、MX4SIO、内蔵 HDD に置いた SD2Cloud と、スロットの通常のメモリーカード。
- SD2Cloud を開く手段: OPL の Apps タブ、wLaunchELF、または ELF ファイルを実行できるその他のプログラム。できれば
  [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader) のような MMCE 対応の OPL を使ってください。対応して
  いない OPL では、MMCE にあるアプリが表示されず、**IGR Bootcard Slot(s)** オプションもありません。そのため Game ID
  のカードでは、IGR でゲームを終了しても sd2psx がゲームのカードのままになり、PS2 は SD2Cloud を開かずにブラウザーに
  戻るので、自動同期は行われません。
- ゲーム後の自動同期には、IGR で SD2Cloud を開く OPL。
- クラウド機能には、Google アカウントと、ネットワークアダプター（薄型モデルは内蔵）を備えてケーブルでルーターに
  接続された PS2。

## インストール

1. [最新のリリース](../../releases/latest) から `SD2Cloud-vX.Y.zip` をダウンロードします。
2. MMCE のルートに展開します。次のものが追加されます。
   - `APPS/SD2Cloud`：アプリ
   - `ART`：OPL の Apps タブで SD2Cloud に表示されるカバーとロゴ
   - `Extras`：ポルトガル語の一文が入った同じアート（`ART` の 2 つのファイルに上書きコピーできます）、SAS
     パッケージ（下記参照）、各設定を説明した `sd2cloud.example.ini`

   設定ファイル（`SD2Cloud/sd2cloud.ini`）は SD2Cloud が初回起動時に作成します。zip には含まれないため、
   新しいバージョンを上書きで展開しても設定は保持されます。
3. OPL の Apps タブから SD2Cloud を開くか、ELF ファイルを実行できる任意のプログラム（たとえば wLaunchELF）で
   `APPS/SD2Cloud/SD2CLOUD.ELF` を実行します。フォルダーは `APPS` になくてもかまいません。
4. 求められたら Google アカウントを接続します（あとで 設定 > Google ドライブ からでも可能）。スマートフォンや
   パソコンで google.com/device を開くか QR コードを読み取り、テレビに表示されたコードを入力します。
5. 続いて SD2Cloud が、自動同期をオンにすることと、すべてのカードを同期することを提案します。

**sd2psx なしの場合** は、zip を USB ドライブ（FAT32 または exFAT）、MX4SIO、内蔵 HDD に展開し、そこから
`APPS/SD2Cloud/SD2CLOUD.ELF` を開いてください。SD2Cloud は設定とデータをそのデバイスに保存します。この場合に
バックアップするのはスロットのメモリーカードで、セーブデータごとに送ります（セーブデータごとのバックアップは
最初からオン）。最初の同期でそれらが提案されます。そのデバイスに sd2psx のフォルダーがあっても、SD2Cloud にとって
はただのファイルです。**ファイル** タブから開いてください。

**sd2psx があり、アプリを別のデバイスに置く場合。** SD2Cloud は USB ドライブ、MX4SIO、内蔵 HDD（exFAT または APA）
にも置けます。`APPS/SD2Cloud` フォルダーをそこに置き、一度そこから SD2Cloud を開いてください。すると SD2Cloud は
自分の場所を記録し、そのデバイスから起動するために SAS パッケージが必要とするドライバーを MMCE
（`SD2Cloud/drivers`）に保存し、以後はその場所で更新されます。設定とデータは MMCE に残ります。

**メモリーカード上の SAS パッケージ。** 自動同期をオンにすると、SD2Cloud は使用中のメモリーカードに SAS（Save
Application System）パッケージを書き込みます。約 240 KB の `APP_SD2CLOUD` フォルダーで、中身は次のとおりです。
- OPL が IGR で実行するプログラム。
- SD2Cloud がどこにあっても開くショートカット。PS2 のブラウザーには専用の 3D アイコンで表示されます。
- sd2psx がない場合は、SD2Cloud のあるデバイスのドライバーも入ります（約 90 KB 増えます）。

SD2Cloud 本体は元の場所に残ります。zip には同じパッケージが `Extras/APP_SD2CLOUD.psu` としても入っており、手動で
別のカードにインポートできます（SD2Cloud 自身の **ファイル** タブでも可能）。そのあと SD2Cloud をその場所から一度
開けば、ショートカットが見つけられるようになります。

**2.0 より前のバージョンからの場合**: バージョン 2.0 では、ドライブ上のバックアップを機器・ゲーム・カードごとに
新しく整理します。最初に起動したときに、SD2Cloud がファイルを新しいフォルダーへ移動することを提案します。
再アップロードは行いません。「あとで」を選ぶと以前の構成のままになり、設定 > Google ドライブ からもう一度選べます。

zip に含まれる [README.txt](package/README.txt) では、各画面を詳しく説明しています（英語）。

## ゲーム後の自動同期（IGR）

1. SD2Cloud で 設定（START）> 自動同期 を開き、**SAS パッケージ** を選びます（アカウントを接続した直後にも提案
   されます）。SD2Cloud は必要な容量（約 240 KB）を表示し、使用中のメモリーカードに `APP_SD2CLOUD` フォルダーを
   書き込む前に確認します。Autoboot を使う場合は、BootCard を使用中のときにインストールしてください。
2. OPL の設定で **IGR Path** を `mc0:/APP_SD2CLOUD/IGR.ELF` にします（sd2psx がスロット 2 にある場合は `mc1:`。
   パッケージのインストール時に SD2Cloud が正しいパスを表示します）。バージョン 1.5 以前がカードの
   `mc0:/BOOT/SD2CLOUD-IGR.ELF` にヘルパーを残している場合、そのパスも引き続き使えます。パッケージをインストール
   すると、そのファイルも更新されます。
3. OPL で **IGR Bootcard Slot(s)**（MMCE のページ）もオンにし、sd2psx のスロットまたは BOTH を選びます。これで
   ゲームを終了すると、OPL はパッケージのある BootCard に戻ります。

これ以降、IGR でゲームを終了すると SD2Cloud が開き、変更されたカードをアップロードして OPL に戻ります。設定の同じ
項目で、パッケージの再インストールや削除ができます。

SD2Cloud は MMCE でもほかのデバイスでも、どのフォルダーにでも置けます。開くたびに自分の場所を記録し（MMCE の
`sd2cloud.ini` に。sd2psx がない場合はパッケージ自体に、そのデバイスのドライバーと一緒に）、パッケージはそこから
起動します。名前を変えた `APPS` のフォルダーも見つけられます。

何もアンインストールせずに同期を一時停止するには、設定で **自動同期** をオフにします。IGR は SD2Cloud を飛ばして、
そのあとに開くはずのプログラムに直接進みます。Google アカウントが接続されていない間も同じです。

**何もインストールしない方法（USB ドライブ）。** OPL の IGR は USB ドライブのプログラムも起動できます。
`APPS/SD2Cloud` フォルダーが FAT32 でフォーマットされた USB ドライブにある場合は、手順 1 を省いて **IGR Path** を
`mass:/APPS/SD2Cloud/SD2CLOUD-IGR.ELF` にします。メモリーカードには何も書き込まれません。このとき OPL は、FMCB が
インストールする `mc?:/SYS-CONF` の USB ドライバー `USBD.IRX` と `USBHDFSD.IRX` を読み込みます。メモリーカードに
SAS パッケージがあれば、SD2Cloud がどこにあってもこれらは不要です。パッケージは MMCE、USB ドライブ、MX4SIO、HDD の
どこからでも SD2Cloud を起動します。

OPL が MMCE にない場合は、`sd2cloud.ini` の `[igr]` セクションにそのパスをデバイスから書きます: `mc?:/`
（メモリーカード）、`mass:/`（USB）、`mx4sio:/`、`ata:/`（内蔵 HDD、exFAT）、または `hdd0:パーティション:pfs:/`
（内蔵 HDD、APA）。たとえば `hdd0:__common:pfs:/APPS/OPL/OPNPS2LD.ELF` です。

## プライバシー

メモリーカードは PS2 からあなた自身の Google ドライブへ直接送られます。ほかのサーバーは関与せず、何も収集しません。
SD2Cloud は `drive.file` スコープを使うため、自分が作成したファイルしか見えません。アクセス権は
[myaccount.google.com/permissions](https://myaccount.google.com/permissions) でいつでも取り消せます。Google のほかに
SD2Cloud が接続するのは GitHub だけで、それも設定で「アップデートを確認」を選んだときだけです。

## ビルド

SD2Cloud は C で書かれており、[ps2dev](https://github.com/ps2dev) のツールチェーン（ps2sdk、ps2sdk-ports、gsKit）を使います。

1. `tools/build_ports.sh` が、4096 ビット RSA に対応した wolfSSL と curl を `ports4096/` にビルドします（Google の HTTPS
   に必要です）。
2. `tools/build_mmceman.sh` が sd2psx のドライバーである mmceman を `third_party/mmceman/` にビルドします（SDK に付属
   するものは、長い転送の途中で sd2psx を止めてしまうことがあります）。
3. Google Cloud Console で種類が「TVs and Limited Input devices」の OAuth クライアントを作成して Drive API を有効にし、
   `src/credentials.h` を生成します: `python tools/make_credentials.py client_secret.json src/credentials.h`。
4. `make` で `dist/SD2CLOUD.ELF` と、`igr/` に SAS パッケージの 2 つの小さなプログラム（IGR ヘルパーとショートカット）
   がビルドされます。`make DEBUG=1` で PCSX2 用のデバッグ版がビルドされます。
5. `python tools/make_release.py` が `package/` のテキストとともにリリースを `dist/` にパッケージします。

`make -C tests` は、PS2 のツールチェーンなしで PC 自身のコンパイラーを使って回帰テストを実行します。
[tests/README.md](tests/README.md) をご覧ください。[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) はコードの地図です（英語）。
