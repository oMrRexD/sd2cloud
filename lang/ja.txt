# Tone: a system application's, polite (です/ます). Errors use "〜できませんでした", questions "〜しますか？". A memory
# card is a "メモリーカード" ("カード" when short), a save "セーブデータ", a backup "バックアップ", to sync "同期", the
# default template the "デフォルト" one. Counts use a counter word (枚 for cards, 個 for saves) or come after a colon.
# A half-width space goes between Japanese and a Latin word or a number ("Google ドライブ", "%d 枚"). The circle
# confirms and the cross goes back, as in Japan (CONFIRM_BUTTON): the texts that name a button name them that way. A
# first translation: corrections by native speakers are welcome.
