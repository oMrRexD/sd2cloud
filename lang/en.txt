# SD2Cloud -- the texts on screen in English: the original, which the other files of this folder translate.
#
# Each text is a line "ID = text". A translation keeps the IDs as they are and changes only what comes after "=".
# - %s, %d, %lld and %02d are filled in by the program (a card's name, a number): keep each one, in the same order.
# - \n starts a new line on the screen. A text that starts with a space starts with "\ " instead.
# - The screen is a TV's, and small: each text has to fit its place. The comment above each one says what it is.
#   tools/check_messages.py measures every text of every language, and GitHub runs it on each pull request.
# - A text left out, or left empty, is shown in English.
# Tone: a system application's. Errors start with "Unable to...", the rest are plain sentences.
# How to translate, and how to add a language: CONTRIBUTING.md, "Translating".
