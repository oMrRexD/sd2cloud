# infinitive ("Копировать"). A memory card is a "карта памяти" ("карта" when short), a save a "сохранение", a backup a
# "резервная копия" ("копия" when short), the default template the "основной" one, to upload "загрузить на Google
# Диск", to download "скачать". A count goes after a colon ("Сохранений: 12"), which reads right with any number. A
# first translation: corrections by native speakers are welcome.
